# Notification (React)

The React version of the Socrates **Notification** (Messages, banners). It renders the same markup and uses the same `notification.css` and tokens as the HTML component, so it looks identical. Source of truth: Figma component set **notification** (Messages page). The Figma specification tables (anatomy, formatting, alignment, colors per variant) are on the HTML page of this component, **Components / Messages / notification**, in the HTML Storybook.

```tsx
import { Notification } from '@socrates/design-system';

<Notification type="default" state="warning" buttonText="Update" onButtonClick={update} onDismiss={() => setOpen(false)} open={open}>
  Your payment method expires next month.
</Notification>
```

## Responsive layout

Figma defines a single width of 820px and no desktop, tablet or mobile variants. The banner fills its container and the text wraps, so the height grows. The 80px and 40px page margins of the Header and Footer are page-level rules and are not part of the banner.

## Behavior and accessibility

Figma defines a close control and an optional Button. Nothing else is interactive, and Figma defines no timer, animation, stacking or queue, so none is built.

- **Dismiss:** the close control hides the banner (it stays mounted with the `hidden` attribute, as in the HTML component) and calls `onDismiss`. A bubbling `ds-notification-dismiss` DOM event is also dispatched, the same event the HTML component fires. The banner does not come back by itself.
- **Controlled or not:** pass `open` and update it in `onDismiss` to control visibility, or leave it out and the banner hides itself.
- **Focus:** if the close control had focus, focus moves to the next focusable element on the page (or the previous one if there is none), so keyboard users are not left at the top of the page.
- **Keyboard:** the close control and the Button are native buttons, so Tab, Enter and Space work. Figma defines no focus look, so a focused control shows the existing `shadow-focus-primary` ring.
- **Accessible name:** the close control is icon-only and is named "Close".
- **Announcements:** only the `alert` state uses `role="alert"`; every other state uses `role="status"`. The four status states also contain a visually hidden word naming the status; `gray` and `white` do not.
