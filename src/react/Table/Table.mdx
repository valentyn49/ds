# Table (React)

The React version of the Test Design System **Table**: the 33-variant **table-cell**, the **header** cell and the **Divider** from the Figma Design Library (Table page), composed as in the Sandbox "Table example" elements. It renders the same markup and uses the same `table.css` and tokens as the HTML component, so it looks identical. The Figma specification tables (sizes, paddings, colors per cell type and per theme) are on the HTML page, **Table / table-cell**, and are not copied here.

```tsx
import { Table } from 'test-design-system';

<Table
  label="Watchlist"
  columns={[
    { title: 'Market', width: 140, sorting: true, sorted: true },
    { title: 'Open' },
    { title: 'Current Subscription', width: 156 },
  ]}
  rows={[
    {
      subscription: 'premium',
      cells: [
        { type: 'market name', name: 'US - Meta Platforms', flag: '🇺🇸', country: 'United States' },
        { type: 'metric', text: '3.99\n3/18/2024' },
        { type: 'button', variant: 'neutral_premium', text: 'Premium Analysis', onClick: open },
      ],
    },
  ]}
/>
```

## States

Figma draws a default row, a hovered row in one Sandbox table, and the subscription tint. It defines no selected, focus, disabled or loading state for rows or cells. Hover is real: move the pointer over a row.

## Market subscription highlighting

A row with a `subscription` (`detailed`, `premium` or `summary`) is tinted with `detailed/50`, `premium/50` or `summary/50` on every cell, including the pinned first column. This is not a selected-row state: it does not change on hover and is not a focus look. The row carries `data-subscription`, and its row header contains the hidden text "Subscribed market, Premium subscription." so the meaning is available to assistive technology without any new visible element. Figma defines no dark tint, so the dark theme draws none.

## Responsive behavior and the pinned column

The table fills its container and scrolls sideways inside its own region (`role="region"`, named, focusable) when the columns do not fit, so it never widens the page. Column widths are kept; columns are never squeezed to fit. With `stickyFirstColumn` the first column stays at the left edge with its own fill, above the scrolling cells, and gets the Figma shadow (4px 4px 6px, black at 16%) once the table has scrolled. Figma draws the shadow in a scrolled state and gives no rule for when it appears, so showing it from the first pixel of scrolling is an implementation decision.

## Behavior and accessibility

- The component is a native `table`: header cells are `th scope="col"`, the first cell of a row is `th scope="row"`, a divider is a `th scope="colgroup"` spanning all columns, and the table has a caption.
- The scroll region is focusable (Tab) and scrolls with the arrow keys. Links and Buttons inside cells are native controls; there is no grid navigation.
- Figma defines no sorting, filtering, pagination, resizing, selection or editing, so none exists.
- Ids are not generated: the table needs none.
