# Button (React)

The React version of the Socrates **Button**. It renders the same markup and uses the same `button.css` and tokens as the HTML component, so it looks identical. Source of truth: Figma component set **Button** (Buttons page). The HTML documentation of this component is in the HTML Storybook.

```tsx
import { Button } from '@socrates/design-system';

<Button variant="primary" size={48} leftIcon="search" onClick={save}>
  Save
</Button>
```

## Behavior and accessibility

- It is a native `<button>`: Enter and Space activate it, and a disabled button leaves the tab order.
- `type` defaults to `"button"`. A button inside a form does not submit it; pass `type="submit"` on the main action.
- Focus shows the existing `shadow-focus-primary` ring on `:focus-visible` only.
- The component forwards its `ref` and spreads any other attribute onto the `<button>`.
- Figma defines no loading state, no link behavior and no toggle, so none exists.
