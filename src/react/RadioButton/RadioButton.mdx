# RadioButton (React)

The React version of the Test Design System **radiobutton**. It renders the same markup and uses the same `radiobutton.css` and tokens as the HTML component, so it looks identical. Source of truth: Figma component set **radiobutton** (Radiobutton page). The Figma specification tables (anatomy, spacing, typography) are on the HTML page of this component in the HTML Storybook.

```tsx
import { RadioButton } from 'test-design-system';

<RadioButton name="plan" value="basic" title="Basic" subtitle="Billed monthly" checked={plan === 'basic'} onChange={(e) => setPlan(e.target.value)} />
```

## Behavior and accessibility

The component is a native `<input type="radio">` inside a `<label>`, so these behaviors come from the browser and stay in sync with the visual state.

- **Click the circle or the label:** selects the radio and deselects the others with the same `name`.
- **Tab:** moves focus into the group, to the selected radio, or to the first one if none is selected.
- **Arrow keys:** move focus to the next or previous radio in the group and select it. Disabled radios are skipped.
- **Space:** selects the focused radio.
- **Names:** the input is named by its title (`aria-labelledby`) and described by its caption (`aria-describedby`, only when the caption is shown). Pass your own `aria-*` props to override them.
- **Group:** wrap related radios in an element with `role="radiogroup"` and an `aria-label` or `aria-labelledby`. Figma has no group component, so none is provided.
- **Focus:** Figma defines no focus look. A focused radio shows the existing `shadow-focus-primary` ring around the circle.
- **Forms:** the radio takes part in forms like any native radio, and `required`, `form` and `name` work.
