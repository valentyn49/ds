# Footer (React)

The React version of the Test Design System **Footer**. It renders the same markup and uses the same `footer.css`, tokens and content as the HTML component, so it looks identical. Source of truth: Figma component set **footer** (Footer page). The Figma specification tables (spacing, typography, colors, responsive rules) are in the HTML Storybook page for the footer and are not repeated here.

```tsx
import { Footer, Logo } from 'test-design-system';

<Footer />                        {/* big, standart */}
<Footer type="enterprise" />
<Footer size="small" />
```

The Figma `resolution` (desktop, tablet, mobile) is **not a prop**. The layout follows the footer's own width through container queries: mobile up to 576px, tablet 577px to 992px, desktop from 993px. The link text and destinations are fixed by the design (Figma gives no destinations, so the links use `#`).

## Behavior and accessibility

- The footer is a `<footer>` landmark. Its two groups of links are `<nav>` regions labelled "Footer" and "Legal"; every link group has a heading that labels it (`role="group"`, `aria-labelledby`).
- Tab moves through the links in reading order. Figma defines no link focus look, so a focused link shows the existing focus ring; Figma defines no hover look either.
- A press on a placeholder `#` link is prevented, so the page does not jump or change its address. This is unresolved: the product has to supply real destinations.
- Container queries decide the layout, so the footer behaves the same in a full page and in a narrower container.
