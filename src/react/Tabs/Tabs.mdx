# Tabs (React)

The React version of the three Socrates tab bars from the Figma **Nav Tabs** page: **tab**, **General tab** and **Small tab**. It renders the same markup and uses the same `tabs.css` and tokens as the HTML component, so it looks identical. The three bars are separate components in Figma, so they are the three values of the `type` prop. The Figma specification tables (sizes, colors, spacing per state) are on the HTML page, **Nav Tabs / Tabs**, and are not copied here.

```tsx
import { Tabs } from '@socrates/design-system';

<Tabs
  type="Small tab"
  mode="dark"
  ariaLabel="Views"
  items={[
    { label: 'Table view', panel: <TableView /> },
    { label: 'Chart view', panel: <ChartView />, icon: true },
    { label: 'Notes', disabled: true },
  ]}
  onValueChange={(index, item) => console.log(index, item.label)}
/>
```

## States

Figma defines the states selected, default, hover and pressed for `tab`; selected, default, disabled, hover and pressed for `General tab`; and active, default, disabled, hover and Pressed for `Small tab` (light and dark). Hover, pressed and focus are real browser states in the CSS; the display below forces them with `previewState` for documentation only. Figma defines no focus state; the focus tile uses the existing focus-primary ring and is not a Figma specification.

## Behavior and accessibility

Figma shows only the tab bars, with no links, panels or description of what a tab does. The semantics below are an implementation choice, based on how each bar is built (the same choice as the HTML component).

<table className="ds-table">
  <thead>
    <tr><th>Type</th><th>Pattern</th><th>Markup</th></tr>
  </thead>
  <tbody>
    <tr><td><code>tab</code></td><td>Tabs that switch a content panel</td><td><code>role="tablist"</code> with <code>button role="tab"</code> and <code>role="tabpanel"</code>; <code>aria-selected</code>, <code>aria-controls</code>, <code>aria-labelledby</code></td></tr>
    <tr><td><code>Small tab</code></td><td>Tabs that switch a content panel</td><td>Same as <code>tab</code></td></tr>
    <tr><td><code>General tab</code></td><td>Navigation</td><td><code>nav</code> with links; the current link has <code>aria-current="page"</code>; a disabled link has <code>aria-disabled="true"</code></td></tr>
  </tbody>
</table>

- **Selection:** only one tab is selected at a time. A click selects a tab and, for `tab` and `Small tab`, shows its panel and hides the others. For `General tab` the clicked link gets `aria-current="page"`. Each selection calls `onValueChange`.
- **Focus:** in `tab` and `Small tab` only the selected tab is in the Tab order (roving tabindex). The arrow keys move between tabs. The panel can take focus. A disabled tab cannot take focus and is skipped by the arrow keys.
- **Activation:** selection follows focus, so arrowing to a tab selects it.
- **Keyboard:** Arrow Left and Arrow Right move to the previous or next enabled tab and wrap at the ends; Home and End go to the first or last enabled tab.
- **Not included:** Figma defines no closable, draggable, reorderable, nested or lazy-loaded tabs, no scroll buttons and no animation, so none are built. Wide bars scroll sideways inside their container.
