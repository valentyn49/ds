# Dropdown (React)

The React version of the Test Design System **Dropdown**. It renders the same markup and uses the same `dropdown.css` and tokens as the HTML component, so it looks and behaves identically. Source of truth: the Figma Dropdowns section (the **dropdown-input** trigger, the **dropdown** menu and the **dropdown item**). The Figma specification tables (anatomy, spacing, typography) are on the HTML page, in the HTML Storybook.

```tsx
import { Dropdown } from 'test-design-system';

<Dropdown
  label="City"
  options={['London', 'Paris', 'Berlin']}
  defaultValue="Paris"
  onValueChange={(value) => save(value)}
/>
```

## Live Demo

The option names (London, Paris, Berlin, Madrid) are sample data to show selection. They are not part of the design specification. The **state** control is a documentation control: it sets `defaultValue`, `disabled` or `validation` on the component, and forces the hover look.

`DropdownItems` is also exported. It renders only the rows of the menu (the Figma **dropdown item**), with the same markup as the HTML `dropdownItemsHTML()`.

## States

The trigger has one variant property, `state`, with five values. The menu item has `type` with two values. Disabled uses the native attribute and error is set through the `validation` prop. The hover look is forced here with a documentation-only attribute. Figma defines no separate open, focus or selected-item state. The hover look is also used while the menu is open and for keyboard focus, and the chosen item is exposed with `aria-selected`.

## Behavior and accessibility

Figma shows a single-choice list that opens from a trigger, so it is a select-style combobox with a listbox. The trigger is a `button` with `role="combobox"`, and the menu is a `listbox` of `option` rows with `aria-selected`.

- **Click the trigger:** opens or closes the menu.
- **Click an option:** selects it, shows its name in the trigger and closes the menu.
- **Click outside:** closes the menu.
- **Keyboard on the trigger:** Arrow Down, Arrow Up, Enter or Space opens the menu.
- **Keyboard in the open menu:** Arrow Down and Arrow Up move through the options, Home and End jump to the first and last, Enter or Space selects, Escape closes and returns focus to the trigger, and Tab closes it.
- **Focus:** stays on the trigger while the menu is open, and the highlighted option is announced with `aria-activedescendant`. With the search field, focus moves to the search field instead.
- **Disabled:** the trigger cannot be focused or opened.
- **Search (when on):** typing narrows the list to options whose name contains the text.

Figma does not define multiple selection, grouping, clearing, creating options or scrolling, so none of them are built. The checkbox icon on an item is shown as drawn in Figma (unchecked) and does not make the list multi-select.
