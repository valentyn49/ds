## Overview

A message banner tells a person something about the product in a short line of text, such as the result of an action or a notice about their account. The Figma **notification** component is a full-width banner with an optional status icon, one text, an optional Button and an optional close control. It comes in two types and six states.

## Behaviors

Figma defines a close control and an optional Button. Nothing else is interactive, and Figma defines no timer, animation, stacking or queue, so none is built.

- **Dismiss:** clicking the close control hides the banner and fires a `ds-notification-dismiss` event. The banner does not come back by itself.
- **Focus:** if the close control had focus, focus moves to the next focusable element on the page (or the previous one if there is none), so keyboard users are not left at the top of the page.
- **Keyboard:** the close control and the Button are native buttons, so Tab, Enter and Space work. Figma defines no focus look, so a focused control shows the existing `shadow-focus-primary` ring.
- **Accessible name:** the close control, which is icon-only, is named "Close".
- **Announcements:** only the `alert` state uses `role="alert"`; every other state uses `role="status"`, so banners are not all announced as urgent. The four status states (warning, success, info, alert) also contain a visually hidden word naming the status; `gray` and `white` are neutral and do not.
- **Button action:** Figma gives the Button no destination or action, so it only fires a normal click.
