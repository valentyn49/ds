## Behaviors

Figma shows only the tab bars, with no links, panels or description of what a tab does. The semantics below are therefore an implementation choice, based on how each bar is built: `tab` and `Small tab` are implemented as tabs that switch a panel, and `General tab` (its parts are called "menu item") as navigation. Please confirm this with the design team.

<div dangerouslySetInnerHTML={{ __html: renderSemantics() }} />

- **Selection:** only one tab is selected at a time. Clicking a tab selects it and, for `tab` and `Small tab`, shows its panel and hides the others. For `General tab` the clicked link gets `aria-current="page"`. Each selection fires a `ds-tabs-change` event.
- **Focus:** in `tab` and `Small tab`, only the selected tab is in the Tab order (roving tabindex); the arrow keys move between tabs. The panel can take focus (`tabindex="0"`). A disabled tab cannot take focus and is skipped by the arrow keys.
- **Activation:** selection follows focus, so arrowing to a tab selects it.
- **Accessible name:** every bar needs a name for its landmark or tablist (the `ariaLabel` prop). The sample name here is generic.
- **Badge and icons:** the icons are decorative (`aria-hidden`). The "Upgrade" badge is part of the link's text.
- **Not included:** Figma defines no closable, draggable, reorderable, nested or lazy-loaded tabs, no scroll buttons, and no animation, so none are built.
