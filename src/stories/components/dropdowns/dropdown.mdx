## Overview

A dropdown lets a person choose one option from a list. The Figma dropdown has three parts: a **dropdown-input** trigger with a title, the chosen value or placeholder, a chevron and a caption, a **dropdown** menu that opens below it, and the **dropdown item** rows inside the menu. The trigger has **5 states** and one size. Items can show a Pro badge, a checkbox icon, a color swatch and a check mark, and the menu can show a search field.

## Behaviors

Figma shows a single-choice list that opens from a trigger, so it is built as a select-style combobox with a listbox. The trigger is a `button` with `role="combobox"`, and the menu is a `listbox` of `option` rows with `aria-selected`.

- **Click the trigger:** opens or closes the menu.
- **Click an option:** selects it, shows its name in the trigger and closes the menu.
- **Click outside:** closes the menu.
- **Keyboard on the trigger:** Arrow Down, Arrow Up, Enter or Space opens the menu.
- **Keyboard in the open menu:** Arrow Down and Arrow Up move through the options, Home and End jump to the first and last, Enter or Space selects, Escape closes and returns focus to the trigger, and Tab closes it.
- **Focus:** stays on the trigger while the menu is open, and the highlighted option is announced with `aria-activedescendant`. With the search field, focus moves to the search field instead.
- **Disabled:** the trigger cannot be focused or opened.
- **Search (when on):** typing narrows the list to options whose name contains the text. Figma defines the search field but not its filtering, so this is the minimal behavior that makes it work.

Figma does not define multiple selection, grouping, clearing, creating options or scrolling, so none of them are built. The checkbox icon on an item is shown as drawn in Figma (unchecked) and does not make the list multi-select.
