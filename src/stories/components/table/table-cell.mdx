## Overview

A table shows structured, comparable information, such as the prices, changes and patterns of many markets side by side, and what the user can do with each market. In Figma it is made of three building blocks and some rows around them.

<div dangerouslySetInnerHTML={{ __html: renderOverview() }} />

The component is a semantic HTML `table`. The first cell of each row is the row header (`th scope="row"`), the header cells are `th scope="col"`, and a Divider is a row that spans all columns. The table sits in a scroll region (`role="region"`, named, focusable) so that wide tables scroll inside it and never widen the page.

## Example 2: Dark Theme Table

Sandbox nodes `6228:21083` (Stochastics) and `6228:21100` (Energy Model), both named **Table example** in *Dashboards_Last Daily Close_Hover*. Both sit on secondary/900. ## Example 3: Mobile Table with a Sticky First Column

Sandbox node `6228:25452`, the element named **Table example** in *mobile*. The table is 620px wide in a 343px preview.
