## Overview

Highcharts visualizes supplied weekly prices and precomputed financial studies. Figma defines `default` (OHLC and studies), `price sparkline` (green area), and `homepage` (blue area). Each has desktop, tablet, and mobile layouts. No other chart types are exposed.

## Tooltip

The Figma “Tooltip logic” section defines the study hints **Hide tooltip chart** and **Show tooltip chart**. They use a white surface, 4 px corners, 8 px vertical / 12 px horizontal padding, Regular 12/18 dark text, and the source shadow and corner. Hover or focus the icon next to a study to inspect it.

Financial point-tooltip content is **not specified** in the source. Supply `formatTooltip` for product-owned plain-text content; otherwise data tooltips are disabled. The mock formatter demonstrates date, values, and OHLC values using the verified white tooltip treatment. HTML is escaped. Highcharts positions the data tooltip within the chart. Tooltip inclusion switches affect only their associated study, independently of visibility.

## States and Interactions

- OHLC monochrome / red–green switch changes bar paint without changing the data.
- 3M, 6M, 1y, 3y, All, and Reset select actual UTC data ranges. Date fields and the native Stock navigator update the same X-axis.
- Study labels show/hide all supplied series in that study. Adjacent icons include/exclude their tooltip values.
- Standard Fullscreen uses the browser fullscreen API. Advanced Fullscreen is enabled when `onFullscreenRequest` is provided; Figma does not define its workflow. The callback receives the requested mode and chart container.
- Optional `marketHref` renders the verified Go to Market Page link. No chart exporting menu, crosshair, automatic plot zooming, or panning is added.

## Responsive Behavior

Auto layout follows the **container**: mobile up to 576 px, tablet up to 992 px, desktop above 992 px. These breakpoints follow application conventions; Figma supplies three reference sizes without breakpoint rules. Explicit `size` values are useful for reference comparisons. Native Highcharts reflow handles plot resizing; a ResizeObserver chooses the header and footer layout. The homepage chart remains 372 px high at every source size.

## Data Integration

```tsx
import { Highcharts } from '@socrates/design-system';
import type { OhlcPoint, StudySeries } from '@socrates/design-system';
import '@socrates/design-system/styles.css';

const data: OhlcPoint[] = [
  [Date.UTC(2025, 9, 20), 120, 126, 118, 124],
  [Date.UTC(2025, 9, 27), 124, 130, 122, 128],
];
const studies: StudySeries[] = [{
  id: 'moving-average', name: 'Moving Average', study: 'movingAverage',
  data: [[Date.UTC(2025, 9, 20), 122], [Date.UTC(2025, 9, 27), 125]],
}];

<Highcharts title="Weekly prices" description="Weekly open, high, low and close in USD."
  data={data} studies={studies} formatValue={value => value.toFixed(0)} />;
```

Area configurations accept `[UTC milliseconds, value | null]` tuples:

```tsx
<Highcharts variant="homepage" title="Weekly closing prices"
  description="Closing values in USD, October 2025."
  data={[[Date.UTC(2025, 9, 20), 124], [Date.UTC(2025, 9, 27), 128]]}
  formatTooltip={({ points }) => points.map(p => `${p.name}: ${p.value}`).join('\n')} />
```

Replace arrays to update data; keep study IDs stable. Data is copied before passing it to Highcharts. Timestamps must be unique and increasing, OHLC high/low must contain open/close, and study IDs must be unique. Study calculations belong to the application. Optional `valueRange` fixes the Y domain; omitted values use the actual data extent. Provide Proxima Nova through the existing font setup.

## Accessibility and Lifecycle

The Highcharts accessibility module exposes descriptions, data semantics, and keyboard navigation. Meaningful `title` and `description` are required. Native buttons and date inputs have accessible names; study controls expose pressed state, and OHLC uses a switch. Reduced-motion preferences disable chart animation. Chart options are local to each instance, with no global theme changes. The official React wrapper updates existing series; unmount cleanup destroys the instance and disconnects observers, including React StrictMode effect replay.

## Implementation Notes

Uses Highcharts Stock 12.6.2 and the official `@highcharts/react` 5.1.0 Stock integration. [Official React integration documentation](https://www.highcharts.com/docs/react/getting-started).

All nine source variants and the adjacent Tooltip logic and options sections were inspected. OHLC option alternatives (checkbox, small tabs, labeled toggle) express the same color mode; the component uses the compact switch shown in the Chart component. The financial data-tooltip content, advanced fullscreen behavior, responsive breakpoints, and plot data values require consuming-product decisions. The documentation fixtures are synthetic and do not reproduce market history.
