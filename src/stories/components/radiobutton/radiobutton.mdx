## Overview

A radio button lets a person choose one option from a set of mutually exclusive choices. The Figma **radiobutton** component is a 20px circle next to a title, with an optional caption under the title and an optional badge after the title. It has **4 states** and one size.

## Behaviors

The component is a native `input type="radio"` inside a `label`. Radio buttons that share the same `name` form one group, so these behaviors come from the browser and stay in sync with the visual state.

- **Click the circle or the label:** selects the radio button and deselects the others in its group.
- **Tab:** moves keyboard focus into the group, onto the selected radio, or onto the first one if none is selected.
- **Arrow keys:** move focus to the next or previous radio in the group and select it.
- **Space:** selects the focused radio if it is not already selected.
- **Disabled:** the radio button cannot be focused or selected, and arrow-key navigation skips it.
- **Value:** the visual state is driven by the input's `checked` value, shown below.
