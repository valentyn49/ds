## Overview

A text area lets a person enter text that can run over several lines. The Figma **text-area** component is a stack of an optional label, the field and an optional footnote. The field can show a left icon and a right icon, and the label can show an info icon. It has **7 states** and one size. It uses the same properties and states as the Figma **input**, with the field filling the component height and the content aligned to the top.

## Behaviors

The component is a native `textarea` with a `label` linked through `for`, and the footnote is linked with `aria-describedby`.

- **Typing:** the field takes multiline text. Enter inserts a new line.
- **Label click:** focuses the text area.
- **Tab:** moves focus into and out of the text area.
- **Disabled:** the text area cannot be focused or edited.
- **Error:** sets `aria-invalid` on the text area.
