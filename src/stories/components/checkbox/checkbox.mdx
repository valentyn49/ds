## Overview

A checkbox lets a person turn one independent option on or off. The Figma **checkbox** component is a 20px box next to a title, with an optional caption under the title. It has **4 states** and one size.

## Behaviors

The component is a native `input type="checkbox"` inside a `label`, so these behaviors come from the browser and stay in sync with the visual state.

- **Click the box or the label:** toggles the value.
- **Tab:** moves keyboard focus to the checkbox.
- **Space:** toggles the checkbox when it has focus.
- **Disabled:** the checkbox cannot be focused or toggled.
- **Value:** the visual state is driven by the input's `checked` value, shown below.

<Canvas of={CheckboxStories.Behavior} sourceState="none" />

Figma does not specify a focus appearance. To keep keyboard use visible, a focused checkbox shows the existing `shadow-focus-primary` ring around the box.
